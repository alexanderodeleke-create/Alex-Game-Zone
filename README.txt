ALEX GAME ZONE 5.0 — PACKAGE

Files:
- index.html: the game
- icon.svg: original app icon
- manifest.webmanifest: installable web app metadata
- sw.js: offline cache support

Try locally:
1. Open index.html in TrebEdit Preview to test gameplay.
2. The install/offline app features require hosting these files together on an HTTPS website.
3. Once hosted, open the site in Chrome on Android and use ⋮ > Add to Home screen / Install app if offered.

Notes:
- High scores are stored locally in the browser on that device.
- Online multiplayer and a shared online leaderboard are not included yet; they require a hosted backend/database.
- This is an original arcade game inspired by broad action-game styling, not an official Free Fire game.
